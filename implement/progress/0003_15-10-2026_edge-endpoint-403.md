# 0003 · 15-10-2026 · Edge สร้างเสียงไม่ได้ (403) — Microsoft เปลี่ยน endpoint/token

## อาการ
Edge ตอบ `Unexpected server response: 403` ทุกคำขอ ทุกเครื่อง (ลูกค้า INKIDEA เจอพร้อมกันหลายคน 14–15 ต.ค.)

## ต้นเหตุ
- `wss://speech.platform.bing.com/.../readaloud/edge/v1` เปลี่ยนไปรับเฉพาะ Sec-MS-GEC รุ่น 2 — `msedge-tts` 2.0.5 ส่งรุ่น 1 → 403
- `msedge-tts` 2.1.0 (13-10-2026) ย้ายไป `wss://api.msedgeservices.com/tts/cognitiveservices/websocket/v1` + คีย์เป็น `Ocp-Apim-Subscription-Key`

## แก้
- ใหม่ `electron/tts/edgeEndpoint.cjs` — แทน static `MsEdgeTTS.getSynthUrl` ให้ต่อ endpoint ใหม่ (ต้นแบบจาก INKIDEA progress 0331)
- `electron/tts/edge.cjs` เรียก `pointMsEdgeTTSEndpoint` หลัง require lib
