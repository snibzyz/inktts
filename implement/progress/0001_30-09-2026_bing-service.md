## เหตุผล
วัดจริง 30-09-2026: Edge Read Aloud `th-TH-PremwadeeNeural` ช้าฝั่ง Microsoft (≈1x realtime ต่อคำขอ + ตอบ 0 byte ~60%).
เสียงเดียวกันผ่าน Bing Translator TTS ตอบ ~2 วิ/ประโยค ไม่เจอ 0 byte · แลกกับคุณภาพ mp3 16 kHz 32 kbps (Edge 24 kHz 48 kbps).
จาก IP เดียว ~10 พร้อมกันไม่เจอ error · ~40 เจอ HTTP 500 ~11% (ลองใหม่ผ่าน). port โค้ดจาก INKIDEA (`electron/audio/bingTts.cjs` + retry จาก `bingProxy.cjs` — ตัดส่วน proxy ออก).
