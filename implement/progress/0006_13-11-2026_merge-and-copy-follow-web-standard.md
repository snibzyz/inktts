# 0006 — รวมไฟล์เสียง + ต่อชิ้น mp3 ได้ไฟล์ตามมาตรฐาน INKREALM ทุกทาง — 13-11-2026

**สั่ง:** Pete 13-11-2026 "แก้ tts อะไรให้ครบยัง ตรวจย่อแก้เลย" (ต่อจาก 0005)

## ตรวจทุกทางที่ INKTTS เขียนไฟล์เสียง

| ทาง | ก่อน | หลัง |
|---|---|---|
| สร้างเสียง → m4a (ทุกความเร็ว) | เข้ารหัส 56 kbps โมโน 24 kHz (0005) | เหมือนเดิม |
| สร้างเสียง → mp3 ความเร็วปกติ | ต่อชิ้นแบบ copy เสมอ — Edge 48 · Bing 32 kbps ผ่าน แต่เครื่องเสียงที่ส่งเกินมาจะหลุด | อ่านชิ้นแรกก่อน · เกินมาตรฐาน = เข้ารหัส 56 kbps |
| **รวมไฟล์ (หน้า "รวมไฟล์เสียง")** | **copy เสมอ** — ไฟล์ต้นทาง 128k (INKTTS รุ่นก่อน 2.1.4 · โปรแกรมอื่น) ได้ไฟล์รวม 128k เว็บต้องแปลงใหม่ทั้งก้อน | อ่านทุกไฟล์ในกลุ่ม · เกินมาตรฐานหรือสเปกไม่ตรงกัน = เข้ารหัส 56 kbps · อยู่ในมาตรฐานทุกไฟล์ = copy เหมือนเดิม (เร็ว ไม่เสียคุณภาพ) |

มาตรฐานเว็บ = ≤ 64 kbps (วัดจากขนาดไฟล์ ÷ ความยาว แบบเดียวกับเว็บ) · ≤ 32 kHz · โมโน

## แก้

- `electron/tts/ffmpeg.cjs`: `parseAudioProbe` (อ่าน `ffmpeg -i`) · `withinWebStandard` · `probeAudio` · `canCopyConcat` (อ่านพร้อมกันทีละ 4) · `ffmpegConcat(..., { reencode })` · ทาง mp3 copy ตรวจชิ้นแรก
- `electron/tts/merge.cjs`: เลือก copy / เข้ารหัสใหม่ต่อกลุ่ม · log บอกผู้ใช้ว่าย่อเพราะอะไร ("ไฟล์ต้นทางเกินมาตรฐานเว็บ (x.m4a 130 kbps · 44100 Hz · สเตอริโอ) → ย่อเป็น 56 kbps")
