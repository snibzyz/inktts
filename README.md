# INKTTS — แปลงข้อความภาษาไทยเป็นเสียง

> **INKTTS** คือโปรแกรมที่ช่วยเปลี่ยนไฟล์ข้อความ (`.txt`) ให้กลายเป็นไฟล์เสียง (`.m4a`)
> เช่น นิยายยาวๆ → ฟังเป็นเสียงในรถ / ก่อนนอน / ระหว่างทำงานบ้าน
>
> ✅ ฟรี · ✅ ไม่ต้องสมัครสมาชิก · ✅ ไม่ต้องใส่ API key · ✅ แปลงทีละหลายไฟล์ได้พร้อมกัน

## 📥 ดาวน์โหลด

ไปที่หน้า **[Releases](https://github.com/snibzyz/inktts/releases/latest)** แล้วเลือกไฟล์ตามเครื่องของคุณ:

| เครื่อง | ไฟล์ที่ต้องโหลด |
|---|---|
| 🪟 **Windows** | `INKTTS-Portable-x.x.x.exe` |
| 🍎 **Mac (Apple Silicon — M1/M2/M3/M4)** | `INKTTS-x.x.x-arm64.dmg` |
| 🍎 **Mac (Intel)** | `INKTTS-x.x.x-x64.dmg` |

**Windows** — ดับเบิ้ลคลิกเปิดได้เลย ไม่ต้องติดตั้ง

**Mac** — ครั้งแรก ให้ **คลิกขวาที่ไอคอน → Open** (ไม่ใช่ดับเบิ้ลคลิก) แล้วกด "Open" ในกล่องเตือน
ครั้งต่อๆ ไปดับเบิ้ลคลิกได้ปกติ

## 🚀 วิธีใช้

### 1. เตรียมไฟล์ข้อความ
- เปิดโปรแกรม จะมีโฟลเดอร์ชื่อ `input/` อยู่ข้างๆ ไฟล์โปรแกรม
- เอาไฟล์ `.txt` (เช่น `นิยายตอน 1.txt`, `นิยายตอน 2.txt`) วางไว้ในนั้น
- จะกี่ไฟล์ก็ได้ — โปรแกรมแปลงพร้อมกันหลายๆ ไฟล์

### 2. เปิดโปรแกรม + เลือกบริการเสียง
- คลิกเมนูซ้ายเลือกบริการที่ชอบ (อ่านเปรียบเทียบด้านล่าง)
- ปรับเสียงผู้พากย์ / ความเร็ว ได้

### 3. กด "เริ่มแปลงเสียง"
- โปรแกรมจะแปลงให้อัตโนมัติ — เห็นความคืบหน้าทีละไฟล์
- ถ้ามีไฟล์ที่พลาด ปุ่ม **"ลองใหม่เฉพาะที่ล้มเหลว"** จะช่วยซ่อมให้

### 4. ได้ไฟล์เสียง
- ไฟล์ `.m4a` จะอยู่ในโฟลเดอร์ `output/` (แยกตามบริการที่เลือก)
- กดปุ่ม **"เปิดโฟลเดอร์ผลลัพธ์"** เปิดดูเลย

## 🎙 เปรียบเทียบ 3 บริการเสียง

ทุกบริการฟรี ไม่ต้องสมัคร — เลือกตามความชอบ

| บริการ | คุณภาพเสียง | ความเร็ว | จุดเด่น |
|---|---|---|---|
| **Microsoft Edge** ⭐ | สูง (Neural AI) | เร็ว | เสียง Premwadee/Niwat ฟังเป็นธรรมชาติที่สุด แนะนำเริ่มที่ตัวนี้ |
| **Google Translate** | กลาง | ปานกลาง | เสถียรที่สุด แปลงนานๆ ไม่ค่อยมีปัญหา |
| **ResponsiveVoice** | กลาง | ปานกลาง | เลือกเพศ ชาย/หญิง ได้ |

> 💡 **ทิป**: เริ่มจาก **Microsoft Edge** ก่อน ถ้าเจอปัญหา (เช่นช้า/พัง) ค่อยลอง Google

## 🔧 รวมไฟล์เสียงเป็นกลุ่มย่อย (Merge)

ถ้ามีไฟล์ตอน 1–100 อยากรวมเป็นไฟล์ 1–10, 11–20, ... เพื่อฟังเป็นชุด — มีเครื่องมือ "รวมไฟล์เสียง" ในเมนูซ้าย

1. เลือกโฟลเดอร์ที่มีไฟล์ `.m4a`
2. กรอกคำนำหน้าชื่อไฟล์ (เช่น `นิยายตอน `)
3. กำหนดจัดกลุ่มละกี่ตอน (เช่น 10)
4. กดเริ่มรวม → ได้ไฟล์ใหญ่ในโฟลเดอร์ `_merged`

## 🔄 อัปเดตอัตโนมัติ

- **Windows portable** — โปรแกรมจะเช็คเวอร์ชันใหม่อัตโนมัติทุก 30 นาที
  ถ้ามีจะดาวน์โหลดเงียบๆ ในพื้นหลัง พอปิดโปรแกรมรอบหน้าจะใช้เวอร์ชันใหม่ทันที (ไม่ต้องทำอะไร)

- **Mac** — โปรแกรมจะ**แจ้งเตือน**เมื่อมีเวอร์ชันใหม่ แต่ต้องคลิกปุ่ม "ดาวน์โหลด" เพื่อโหลดเอง (Mac ไม่อนุญาตให้โปรแกรมเปลี่ยนตัวเองอัตโนมัติถ้าไม่ได้เซ็นต์ดิจิทัล)

## ❓ ปัญหาที่พบบ่อย

**Q: เปิดไม่ได้ บอกว่า "ไม่รู้จักผู้พัฒนา" / "INKTTS is damaged"**
A:
- Windows: คลิก "More info" → "Run anyway"
- Mac: คลิกขวาที่ไอคอน → Open (อย่าดับเบิ้ลคลิก) แล้วกด "Open" ในกล่อง

**Q: แปลงแล้วได้ไฟล์ขนาด 0 KB / ฟังไม่ได้**
A: บริการนั้นอาจโดน rate limit ลอง:
- กดปุ่ม "ลองใหม่เฉพาะที่ล้มเหลว"
- หรือเปลี่ยนเป็นบริการอื่น (Google เสถียรที่สุด)
- หรือเปลี่ยน preset เป็น "ช้าแต่ปลอดภัย"

**Q: เสียงเร็ว/ช้าเกินไป**
A: ปรับ "ความเร็วเสียง" ในหน้าตั้งค่าของแต่ละบริการ
- Edge: `+30%` = เร็วขึ้น 30% (ลองใส่ `+0%` ถ้าอยากปกติ)
- Google/RV: เลื่อน slider ความเร็ว

**Q: จะแปลงข้อความที่ยาวมากๆ ได้มั้ย**
A: ได้ — โปรแกรมจะตัดเป็นชิ้นย่อย แปลงทีละชิ้น แล้วต่อกันให้อัตโนมัติ (ไม่มีจำกัดความยาว)

**Q: เปลี่ยนโฟลเดอร์ input/output ได้มั้ย**
A: ได้ — ไปที่เมนู "ตั้งค่า" เลือกโฟลเดอร์ใหม่ จะจดจำไว้รอบหน้า

## 👨‍💻 สำหรับนักพัฒนา

INKTTS เป็น **Electron + React + TypeScript** desktop app
อยู่ในตระกูลเดียวกับ [INKIDEA / INKCRAW / INKWRIGHT](https://github.com/snibzyz)

```bash
pnpm install         # ติดตั้ง dependencies
pnpm dev             # รันโหมดพัฒนา (Vite + Electron hot-reload)
pnpm package:win     # build Windows portable .exe
pnpm package:mac     # build macOS .dmg (ต้องรันบน Mac)
pnpm release 2.1.0   # bump version + tag + push → trigger CI build
```

ต้องมี Node.js 20+ และ pnpm 9+

โครงสร้างโค้ดละเอียดดูที่ [`.claude/CLAUDE.md`](.claude/CLAUDE.md)
